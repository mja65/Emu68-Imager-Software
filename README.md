This is the repository for the Emu68 Imager tool for version 2 and up. The most recent version of the tool is found under the "Releases" [tab](https://github.com/mja65/Emu68-Imager-Software/releases). Simply download the latest version, extract, and run the Emu68Imager.cmd file.

Unfortunately, due to the nature of the tool being a collection of PowerShell scripts, on occasion automated alerts can be triggered in Microsoft Defender. If you get a suffix in the detected threat with "ml" at the end, it is based on Machine Learning. When identified these are reported to Microsoft as false positives. If you get such an error and are unsure, by all means raise an issue and I can confirm there is no issue (and raise the report with Microsoft. They can also be directly reported as false positives to Microsoft at the following [link](https://www.microsoft.com/en-us/wdsi/filesubmission).

Please note, that commits in the repository which are not included in a release should be considered a Work in Progress! They may cause issues or just not work at all. You have been warned!

Full documentation is available [here](https://mja65.github.io/Emu68-Imager/).
